## 一、幼儿期（幼儿园大班 - 小学低年级）

### 1.1 抚养方式

- **幼儿园大班开始**：父母去福州长乐打工，由爷爷奶奶照顾
- 即使父母没有外出务工也需要上班，生活上以爷爷奶奶陪伴为主
- **幼儿园**：爷爷给换衣服，接送上下学
- **一二年级**：仍被喂饭
- **五年级开始**：自己吃饭
- 父母离家期间：佳钰自述"对于父母离家没什么太多的想念和感觉，至少记忆里是这样的"。第一次意识到自己是留守儿童是学校要求填表格的时候

### 1.2 人格特质（这一时期）

- 自信、直接、勇于争取
- 外向、女汉子、喜欢揍男生、觉得自己很有力量
- 邻里关系融洽，小孩玩得很好
- 表弟（姑姑的儿子）放长假会一起玩
- 喜欢玩芭比娃娃（爷爷买了几十个）、烹饪玩具、贴纸等

### 1.3 学业与兴趣

- 学习成绩好，名列前茅
- 喜欢画画 → 家人报兴趣班 → 一直画得很好 → 黑板报被夸奖
- **一年级下册**：发现不写作业也能考好 → 开始欺骗家人说没作业/写完了 → 不喜欢写寒暑假作业 → 但不影响学习成绩
- 总体状态：**"玩中学、学中玩，依赖兴趣与氛围做到名列前茅"**，在进入高中之前没有所谓的努力学习过

### 1.4 学校生活与早期社会创伤

**一二年级**：班长。

**三年级事件**：
- 老师问"想选班长的举手" → 佳钰自然举手 → 老师选她而非另一个女生魏
- **魏的小团体开始针对她**：
  - 佳钰管理班级严格但轮到自己时打马虎眼 → 小团体背地去办公室打小报告
  - 佳钰喜欢一个男生 → 小团体在她路过男厕所去女厕所时把她推进男厕所 → 男生骂"神经病" → 小团体嘲笑她
  - 一次误会 → 老师生气当场辞掉佳钰的班长
- **佳钰的应对**：写纸条解释 → 讲明白希望老师给她第二次机会 → 在竞选中成为女生候选人断层第一名

### 1.5 早期技术接触与性意识

- **三年级**：有了电脑 → 开始上网 → 接触日本动漫、网页游戏
- **四年级**：接触了何为性爱，学会了夹腿高潮

## 二、小学高年级（五六年级）——第一次收缩

### 2.1 社会世界的恶意

郁结在心里、未被消解的情绪经验：

**身体羞辱**：
- 佳钰笑起来会露出牙龈（没有严重到需要矫正的地步）
- 男生直接说："你能不能别这样笑，很吓人"
- 男生有很多看似夸奖实则阴阳的起哄

**教师的背叛**：
- 六年级语文老师兼班主任并不看好佳钰
- 小升初末期考试：班里三个人被选为上台演讲的人，名单交上去
- 老师选了佳钰（因为佳钰是她认识的升旗手）
- 老师在背后跟A说："以为会选你没想到选了她"
- 跟B说："据说最后一次上台演讲的考的都会很差"
- 佳钰知道这些背后的话，情绪无法消解

### 2.2 心理后果

## 五、高中——第一次崩溃

### 5.1 入学起点

- 去了市里读书
- **衡水模式的封闭式寄宿制学校**（高度军事化管理、高强度学业压力、全员住宿、空间封闭）
- **蹭线进入**的成绩
- 进入普通班

### 5.2 高一上学期

- 努力的同时获得了**很温暖的人际氛围**

### 5.3 高一下册：分班后

- **分班** → 看到周围全都是比她更优秀的人 → 不知所措
- **雏鸟效应**：与舍友关系变好

### 5.4 第一段亲密关系（舍友）

**对方**：
- 有抑郁症会自残的二次元
- 有天分但性格扭曲

**关系的动态**：
- 注意到佳钰的M属性 → 激发
- 近距离的肢体接触
- 佳钰一直有旺盛的、自己解决的性需求
- 两个人过分腻歪：咬痕、亲吻
- 佳钰觉得疼痛但**反驳无效**
- 过度亲密导致**全年级流言蜚语**

**心理控制**：
- 否定佳钰的感受，说佳钰"什么都不懂"
- 轻视佳钰的付出

**社会后果**：
- 过度依赖舍友 → 之前温暖的人际关系再次出现裂痕
- 错过了与新班级同学融入的机会

### 5.5 高二

- 迎合舍友的后果是一个带有**偏见与疏离**的陌生环境
- 成绩还不错 → 获得了基本的尊重
- **高二下册末尾**：父母接受了佳钰的提议，为她争取了校内的**教师宿舍作为单人宿舍**——"否则问题会更严重"

### 5.6 崩溃的后果

- **抑郁症焦虑症**（药物剂量顶格，中重度）
- 躯体化
- 社交环境恶化（被小人的嫉妒摁死在谷底）
- 休学
- 高考只上了**二本**（三明学院）

### 5.7 环境因素的分析意义

**衡水模式——创伤发生在无处可逃的封闭系统里**

衡水模式的核心特征是高度军事化管理、全员住宿、严格作息管控、空间封闭。在Goffman的概念中这属于**全控机构（total institution）**——个体的一切行为都在统一管控下，没有私人空间，没有退出机制。

这个环境对创伤的影响：
- "全年级流言蜚语"发生在封闭生态系统中——所有人都知道，没人能假装不知道。社会污染是全面且无法躲避的
- 舍友的边界侵犯发生后，物理上无处可退。不是"回家缓一缓"，是每天在同一个房间面对同一个人
- "反驳无效"不只对舍友——对整个系统也无效。衡水模式的高中不会因"舍友关系不适"而调整安排
- 高压学业 + 亲密关系创伤 + 社会流言 + 物理封闭——四重压力同时叠加

五六年级的社会恶意虽然弥散，但每天可以回家。高中的创伤是具体、亲密且**无处可逃**的。这可能部分解释了后果严重程度的差异：同一个核心信念（"我讨人厌"→"你什么都不懂"）被触及时，一个是可退回避难的，一个是无路可退的。

**单人宿舍——一次及时的危机干预**

高二下册末尾，父母接受佳钰的提议，为她争取到校内教师宿舍作为单人宿舍。注意几点：

- **佳钰主动提议**——她识别了自己的需求（需要物理安全距离），并动用可用资源实现它。这是三年级"写纸条争取第二次机会"同一个公式在更复杂情境下的应用。这一次没有翻盘，但**减损**了——"否则问题会更严重"
- **父母响应了她的需求**——和母亲初一冲突后的改变属于同一模式：当她清晰表达需要什么，父母最终会回应。这个模式强化了"关系可以修复"的信念，也让"主动争取"的策略没有彻底失效
- **物理边界是心理边界重建的前提**——在经历了舍友对身体边界的系统性侵犯后，有一个锁得上的、不与人分享的、不被监视的房间，是恢复自主感的基础条件，而非奢侈
- **"否则问题会更严重"**——确认了当时的严重程度已逼近某个临界点。单人宿舍是一次成功的危机干预
