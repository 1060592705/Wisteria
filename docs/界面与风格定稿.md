# 界面与风格定稿

> 建立：2026-08-20。依据：用户与 Claude 逐项共议 + 19 张小红书参考图的外部 AI 描述（两批）+ 已确认需求。
> 本文件是 UI 实现规格——开发时照着做。每节标 [已确认] / [待确认]。
> 配套：docs/Wisteria实施方案.md（功能与架构）、docs/Kaoru人设.md（人格）。

## 一、设计语言：手账小票风 [已确认]

App 的名字叫 Wisteria，视觉语言只有一句话：**纸 + 票 + 贴纸**。

三层结构 + 一层质感：
1. **纸底**：米白旧纸、颗粒质感、撕纸边——整个 App 是一本摊开的纸
2. **小票结构**：等宽字、虚线分隔、对齐行、小计、锯齿撕边、章、条形码——负责"干爽"：结构可解析、一眼看懂
3. **手账贴纸**：胶带、火漆、回形针、纸夹——负责"温柔"：他留的言、盖的章、贴的纸（便利贴弃用 [2026-08-20]）
4. **玻璃质感** [已确认 2026-08-20]：浮在纸底的卡片半透明 + 背景模糊 + 细白描边 + 内高光（毛玻璃），落在月历框、他的气泡；小票保持纸感（它是打印物）

**一天的生命周期** [已确认，用户提出]：
- 白天：主页待办 = 线圈本撕下的**草稿纸**（手写感、划掉、随手加行）
- 晚上：睡前记录 = **结账打印**（草稿变成正式打印小票、盖红章、归档进账本）

覆盖的风格关键词：干爽（小票结构）/ 粉丧（脏粉情绪色）/ 古早日系（昭和票据、点阵、弥散）/ 温柔（手账层）——四个口味一次收住。

## 二、信息架构 [已确认]

- 启动：开屏页 → 从通知进入 → 直达聊天页；正常打开 → 主页
- 底部 4 tab：**chat / home / diary / settings**（微信式）
- 页面清单：
  - 开屏（Wisteria 花体 + 自动进入动画；夜里变暗）
  - 主页（草稿纸待办 + 月历框 + 定时事项 + 陪伴天数 + 睡前入口灯）
  - 月历全页（点月历框展开；连续天数卡）
  - 聊天页（Kaoru 消息流；M1 只读、M2 可输入）
  - 结账页（睡前记录，打印仪式）
  - diary 两分区：**账本**（每晚打印票，打印体）+ **日记**（有感而发自由写，手写稿纸风）
  - Kaoru 主页（点聊天页头像进入：手账纸档案页）
  - 记忆页（Kaoru 主页进入：他记住的事，可看可改可删）
  - 周分析 / 月末信（聊天流内收信阅读）
  - 设置（系统项）

## 三、色板 [已确认，色值从参考图收敛]

| 用途 | 色值 | 来源 |
|---|---|---|
| 纸底（全局背景） | #F4F2F0 | 打印店提示词压冷（2026-08-20 用户选定 B） |
| 深纸 / 卡其（次级底） | #E8E5E1 | 同上 |
| 主脏粉（情感强调、"已吃"/完成、章） | #D4A5A5 | 打印店提示词灰玫瑰 |
| 浅脏粉（用户气泡、底纹） | #E6DADA | 压冷；聊天气泡例外沿用 #F3D3D6（A 组暖色） |
| 灰脏粉（卡片、柔化） | #C2B5B5 | 压冷 |
| 灰蓝（结构、图标、冷静信息） | #9BAAB8 | 打印店提示词石板蓝 |
| 墨字（正文标题） | #3D3535 | 打印店提示词 |
| 夜里模式 | 全盘降饱和 + 灰度网点 | 黑白版画 |

> 2026-08-20 用户删色：橄榄绿、金棕、红章、弥散紫、淡紫不再使用——色板收敛为纸＋粉＋灰。原橄榄绿（已吃/完成）与红章（盖章）的角色并入主脏粉；原金棕（天数/标签）并入灰蓝。正合"点缀色克制"原则（见附录二）。
> 2026-08-20 用户评第二份打印店风格提示词（灰玫瑰 #D4A5A5 + 石板蓝 #9BAAB8）"太暖色了，想要有点丧丧的" → 调参台出三套方案对比 → **用户选定 B 打印店·灰粉**：打印店方向压冷、零手写（花体 logo 除外）。

用色规则：大字内容用墨字；情感与状态（已吃、完成、章）用脏粉；结构元素用灰/蓝灰；装饰靠纸纹与留白，不另立颜色。

## 四、字体方案 [方向已确认，观感由调参台定]

原则：iOS 内置为主，手写体打包一个开源字体（体积可控）。

- 正文：PingFang SC（系统）
- 小票明细行：Menlo 等宽（系统）
- 手写体 [2026-08-20 撤回]：B 方案选定后全 App 零手写——草稿纸、Kaoru 的话、日记都用 PingFang；志忙行暂退场（想加回来随时说）
- 花体 logo（开屏 "Wisteria"）[已确认]：**Parisienne**
- 海报体英文（小票抬头、章文）[已确认]：**Bebas Neue**（OFL 海报展示体）
- 层级：小票抬头 > 区标题 > 正文 > 小字注释；数字（天数、单据号）用等宽或衬线大号

## 五、各页组件清单

### 开屏
柔焦脏粉雾背景 + 旧纸颗粒；中间 "Wisteria" 花体；动画自动播放、自动进入主页（无需点击）[已确认 2026-08-20]；23:00 后画面为暗色（他睡了）。参考：Virgil&Scarlett。

### 主页（白天 = 草稿纸）[已确认]
- 顶部一行：Kaoru 问候（M1 模板 / M2 AI）+ 右侧陪伴天数小字
- 草稿纸卡片（主角）：线圈本撕纸——左侧一排圆孔 + 沿孔撕下的毛边、行间细实线；圆角 20px（B 组打印店）
  - 待办行：PingFang 打印体、行间细实线；勾掉 = 划删除线 + 行尾 ✓；点击行尾 = 勾 / 取消
  - 添加 = 纸面底部"随手写一行"（输入后成为新待办行）
  - 固定待办：每天自动出现（设置里管理）
  - 定时事项：带时间戳的行（"14:00 和导师开会"），到点 Kaoru 发消息提醒
  - 留言条：Kaoru 的留言（M1 模板、M2 真留言）；样式不用便利贴 [2026-08-20]，候选：小票背面附言 / 蜡封纸条（待定）
- 月历框：粉调日历；格内药点（主脏粉=吃了 / 灰=没吃 / 空=没记录）；今天格子放大+描边+呼吸光，点击=记"已吃"（当天内可撤销）；下方"少/多"图例；点击展开月历全页。参考：Memories
- 睡前入口：晚上亮起"该结账了"灯
- 夜里 23:00 后整页降饱和变暗（他睡了）

### 月历全页
- 月历网格（同框内编码）+ 纪念日标记（首次使用日、连续里程碑）
- 顶部卡 [2026-08-20 款式=Hero统计卡（BaiShou 回顾页）]：深底大字横幅（Bebas 大数字「27 DAYS」式）+ 小统计卡（早于目标起床 X / 共同纪念日 Y）；连续记录天数（补记计入）
- 图例：药点三色 + 小票存在标记（那天有结账票 = 格子下沿短线）

### 聊天页 [已确认]
- 顶部：波浪花边；他头像 + 名字 + 状态行（**他在** / 他安静地想事情 / 他睡了——对应主动档位与静默时段）
- 消息流 [2026-08-20 款式=三行头像款（戊）]：方块直角头像 a×a；头像旁侧三行信息、行高 a/3——他：昵称/日期/时间，你：空/日期/时间（空行让两侧日期时间对齐）；气泡在头像下方、贴聊天区边缘、无尖角；圆角=贴头像的上角 4px 小圆、其余 16px 大圆（他左上 / 你右上）；他的气泡白底玻璃、你的气泡 #F3D3D6
- 功能消息：需要选择/确认的消息挂**竖排选项列表**（统一样式、不靠颜色区分）——版式=字母式：A./B./C. Bebas 前缀、细实线分隔、选中文字灰玫瑰 [2026-08-20 已确认]；吃药=吃了/没吃、起床=确认/改目标、结账=没结清带去明天/不带…；周分析/月末信以"信"的样式落流
- 输入框（M2 起）[2026-08-20 款式=戊款同源]：圆角输入条 + 表情按钮 + 发送（流式时变停止）；占位"给薰写点什么…"；流式逐字；retry 按钮
- 点头像 → Kaoru 主页
- M1 只读：消息流 + 通知落消息

### diary 两分区 [已确认]
- **账本**：每晚打印的小票按日期排（打印体、锯齿、红章、他的落款）；点开任意一天回看完整小票
- **日记**：有感而发自由写（稿纸打印体风）；与每日记录分开；按时间排

### 结账页（睡前记录 = 打印仪式）[已确认]
流程：他发消息 → 点入结账页 → ① 草稿自动整理成小票（明细/小计/TOTAL）扫一眼 → ② 定明天：目标起床时间（自动建议 = 今天实际起 − 30~45 分钟，可改）+ 没结清的要不要带到明天 → ③ 点【打印】：草稿"送入打印机"动画，哒哒哒出正式小票 → ④ 章盖下（主脏粉）：全清「PAID・谢谢」，有未结清「明日再续」→ ⑤ 底部 Kaoru 手写一句（M1 模板 / M2 AI）→ 归档账本。
自由文字：可写可不写（位置待定：留言区 / 小票背面 [待确认]）。

### Kaoru 主页（手账纸档案页）[已确认]
不要古早网页壳；要"语言与排版舒服"。手账纸页，内容分节：
- PROFILE：名字 Kaoru（薰）、存在设定（坦诚的 AI，住在 Wisteria 里）
- 性格：温柔照顾型（详见 docs/Kaoru人设.md）
- 他的世界：Wisteria 的设定小段
- TIMELINE：Day 01 遇见你 / 纪念日 / 里程碑（距连续 100 天还有 X 天）
- 三张数据卡：陪伴天数 / 记忆数量 / 下个纪念日
- 入口：记忆页、他的作息（静默时段）、主动消息档位、对你的称呼

### 记忆页
他记住的事：三层记忆可视化（持久 / 近期 / 卡片），可编辑可删除 [2026-08-20 款式=卡组衰减（InternalBeyond）]：统计胶囊（记忆/持久/卡片数量）+ 记忆卡（标题/摘要/标签）+ 衰减进度条（记得多深一眼可见、淡出仍可唤起）。

### 设置
系统项列表（通知、目标起床时间、默认待办管理、AI 模型与 key、数据导出 [M3+]）；纸底细线风格。

## 附录二：设计语言依据（外部提示词，用户认可）

> 2026-08-20 用户提供的外部 AI 对参考图的共性提炼，用户表示"还挺符合我想要的风格"——作为设计语言的正名与校验依据存档。

### 色彩体系：低饱和高明度的「奶油滤镜」
- 主色调：奶白、米灰、浅粉、雾蓝、淡紫、薄荷绿等高明度低饱和色，几乎无纯黑或高饱和色
- 对比度极低：文字与背景对比柔和，甚至刻意降低透明度制造朦胧感
- **点缀色克制：通常只用 1-2 个低饱和彩色作为情绪色，其余为黑白灰**

### 质感与材质：数字世界里的「手工温度」
- 把实体材质数字化：纸张纹理（收据、手账拼贴、信纸）、织物与蕾丝、复古印刷（线稿版画、半调网点、ASCII 字符画）、火漆/胶带/邮票

### 排版逻辑：去网格化的「呼吸感」
- 16-24px 以上大圆角卡片，全圆角胶囊按钮
- 非对称拼贴，元素像剪贴簿随意叠放
- 大量留白；毛玻璃与弥散渐变让硬边变柔软

### 字体气质：手写体与衬线体的混排
- 英文：Script 花体 + 优雅衬线体，替代无衬线黑体
- 中文：细宋、仿宋或手写体，字号偏小、行距宽松
- 中日英三种文字以不同字号/字重/颜色穿插，排版即装饰

### 交互与界面范式
- 拟物隐喻：清单→收银小票、日记→手账本、聊天→书信
- 状态可视化：进度条、纪念日计数
- 简笔手绘风图标

### 情绪内核：私密、治愈、「梦核」感
- 数字避风港：时间感模糊、空间感私密、情绪值柔和

**公式**：奶油色底 + 大圆角卡片 + 1 种实体材质（蕾丝/纸张/纱布）+ 手写花体英文标题 + 毛玻璃/弥散效果 + 非对称拼贴排版

### 与本稿的对应关系
- 色板：按"点缀色克制"执行——删掉橄榄绿/金棕/红章/弥散紫/淡紫，收敛为纸＋粉＋灰（情绪色只剩主脏粉＋灰蓝，正是"1-2 个低饱和彩色"）
